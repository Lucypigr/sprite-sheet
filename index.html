如何使用

角色 Sprite Sheet

  1. 上傳圖片：任何角色圖（手繪、AI 圖、3D 截圖都可以），會自動去背 → 裁切 → 縮成指定像素高度 → 套用調色盤 → 加外框。
  2. AI 生成：輸入描述（中英文皆可），透過免費的 Pollinations.ai 生成角色，再自動像素化。
  3. 程序生成：完全離線，依描述關鍵字組合出像素小人 / 史萊姆 / 怪物。
  4. 勾選要的動畫（待機、走路、跑步、攻擊、跳躍、受傷、死亡、施法），調整每個動畫的影格數與 FPS。動畫是以像素級變形（呼吸、雙腿分離擺動、傾斜、擠壓伸展、旋轉、閃白）自動產生的。
  5. 下載 ZIP：包含 PNG、Godot 4 的 SpriteFrames .tres、Aseprite 相容 .json。

VFX 特效

16 種程序生成特效（爆炸、火焰、斬擊、魔法陣、閃電、治療、冰刺、傳送門、衝擊波…），可調尺寸、影格、配色、密度，循環特效保證首尾無縫。開啟「2.5D 地面透視」可得到貼地的橢圓魔法陣 / 衝擊波。

地圖圖塊

選擇上下兩層地形，產生 16 張角落自動拼接圖塊 + 隨機變化款。匯出的 TileSet 已設定好 Terrain（Match Corners），在 Godot 的 TileMapLayer 直接用地形筆刷畫即可。支援 2D 正方形與 2.5D 等角（含方塊厚度）。

Godot 4 設定

  • 專案設定 → Rendering → Textures → Default Texture Filter 改為 Nearest，像素才不會糊。
  • 把 ZIP 解壓到專案根目錄（res://）；若放子資料夾，請在 .tres 內修改 res:// 路徑。
  • 角色：AnimatedSprite2D → Sprite Frames → 載入 .tres，$AnimatedSprite2D.play("walk_right")。
  • 圖塊：TileMapLayer → Tile Set → 載入 .tres → Terrains 分頁畫圖。

所有處理都在瀏覽器本機完成，圖片不會上傳（AI 生成功能除外，只會送出文字描述）。
